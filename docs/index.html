FlyRank Machine Learning Internship Capstone

Ranking Webpages for Next-Month Click Decline

An honest comparison of a CTR baseline and Logistic Regression for prioritizing webpages for content review.

Author: Suhail Ahmed

Lane: Refresh / Content Opportunity Scoring

Abstract

This capstone examines whether February search and engagement signals can help prioritize webpages that later experience lower average daily clicks in March.

The analysis uses 23,703 webpages from 19 anonymized clients. Six February-only features were evaluated using a client-grouped holdout, ensuring that all four test clients were unseen during model training.

A simple February click-through rate baseline was compared with Logistic Regression. Both methods achieved 100% Precision@20 and 98% Precision@50. The CTR baseline achieved slightly higher average precision: 0.8755 compared with 0.8619 for Logistic Regression.

The simpler CTR baseline performed slightly better than the machine-learning model. Therefore, the final recommendation queue uses February CTR as its ranking signal.

The final output is a ranked decision-support queue with warnings for low-volume pages where CTR may be unstable. The results are observational and specific to this dataset, validation split and the February-to-March 2026 period.

Problem Statement

Content teams may manage thousands of webpages but have limited time for manual review. They need a practical way to identify which pages deserve attention first.

Can February search and engagement signals help rank webpages that are likely to experience lower average daily clicks in March?

The goal of this project is not to automatically decide that a page must be refreshed, deleted or rewritten.

Instead, the project creates a ranked review queue that helps content teams investigate potentially declining pages more efficiently.

Decision supported

The output supports a simple operational decision: which webpages should a content team review first?

Unit of analysis

Each row represents one anonymized webpage belonging to one anonymized client.

Target

The binary target records whether a webpage had lower average daily clicks in March 2026 than in February 2026.

A target value of 1 means that average daily clicks declined. A target value of 0 means that they stayed the same or increased.

Dataset and Time Windows

This project uses anonymized webpage performance data from the FlyRank internship warehouse.

The analysis began with 23,742 webpage records. After removing rows that could not be used safely for modelling, 23,703 rows remained.

Feature window

Only February 2026 information was used as model input.

The six features were:

  • Average daily impressions
  • Average daily clicks
  • Average search position
  • Average daily sessions
  • Engagement rate
  • Click-through rate

Outcome window

March 2026 data was used only to create the later outcome label.

A webpage was labelled as a decline when its March average daily clicks were lower than its February average daily clicks.

Privacy protection

The analysis uses anonymized client and content identifiers. No client names, domains, private queries, access tokens or raw warehouse exports are published.

Methods

Baseline

The baseline ranks webpages from highest to lowest February click-through rate.

This provides a simple and interpretable benchmark that the machine-learning model must outperform.

Machine-learning model

Logistic Regression was selected because it is suitable for binary classification and its feature coefficients can be interpreted.

The six February features were standardized before training so that differences in feature scale did not dominate the model.

Evaluation metrics

The project focuses on ranking quality because the practical goal is to identify which webpages should be reviewed first.

  • Precision@20: the percentage of actual declines among the 20 highest-ranked webpages.
  • Precision@50: the percentage of actual declines among the 50 highest-ranked webpages.
  • Average Precision: ranking quality across the full precision-recall curve.

Model comparison

The CTR baseline and Logistic Regression were evaluated on exactly the same unseen test rows using the same metrics.

The simpler baseline was preferred when the machine-learning model did not produce a measurable improvement.
